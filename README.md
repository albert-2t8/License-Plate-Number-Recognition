# License-Plate-Number-Recognition
This project recognizes license plate numbers using neural networks and the backpropagation algorithm.

How to Run the Project

Follow these steps to execute the program:

-Select a license plate image: You can choose one of the following images:
             
             im4.jpeg
             img5.jpeg
             img6.jpeg
             img7.jpeg

-Set the expected labels: You can modify the values in labels_test[] to match the actual numbers on each license plate image. This allows you to evaluate the model's accuracy on the test dataset.

-Prepare the dataset: Make sure the Imagenes_binarizadas folder, containing the digit images, is located in the same directory as the source code.

-Run the program: Execute Code.py to start the license plate number recognition process.
